ℹ️ Reglas clave de Normas APA 7ma Edición para páginas web

Las citas bibliográficas electrónicas siguen una estructura estándar basada en cuatro elementos: ¿Quién? (Autor), ¿Cuándo? (Fecha), ¿Qué? (Título) y ¿Dónde? (Sitio web y URL).

Páginas web con autor: Apellido, Inicial. (Año, Día de Mes). Título del documento. Nombre del Sitio. https://...
Autor institucional u organización: Nombre de la Entidad. (Año). Título. https://... (si el autor y el sitio son idénticos, no se repite el sitio).
Sin fecha conocida: Se utiliza (s.f.) ("sin fecha") y se recomienda incluir la fecha de consulta/recuperación.
Citas en el texto: Parentética: (Autor, Año). Narrativa: Autor (Año). Para fuentes sin autor se usa el título entre comillas.

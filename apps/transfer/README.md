# Transfer — AirDrop Web & Código QR

> Aplicación web cliente de transferencia instantánea de archivos y textos entre dispositivos en la misma red local estilo AirDrop y generación de códigos QR para escaneo móvil.

## Características

- **Modo AirDrop (Radar de Red Local)**:
  - Detección reactiva de dispositivos conectados a la misma red local.
  - Radar visual con animación y avatar según el tipo de dispositivo (computadora, móvil, tablet).
  - Envío P2P con confirmación: al tocar el dispositivo destinatario, aparece un cartel en su pantalla solicitando aceptar la descarga o copiar el texto.
- **Modo Código QR**:
  - Generación de código QR dinámico para descargar archivos o copiar texto escaneando directamente desde la cámara de un teléfono móvil.
  - Soporte de enlace directo y hash para compartir instantáneamente.
- **Multiarchivo y Texto Libre**:
  - Subida de uno o varios archivos simultáneos de cualquier extensión con cálculo de tamaño.
  - Selector de texto para enlaces, contraseñas, notas o fragmentos de código.
- **Privacidad y Cero Servidor**:
  - Todo el intercambio ocurre en el cliente mediante canales locales y señalización en memoria. Los archivos nunca se almacenan en servidores externos.
- **Diseño Integrado**:
  - Paleta oscura (`#0C0C0E`), acento dorado (`#D4A843`), tipografía Geist, feedback sonoro sintético y menú de aplicaciones de Tools Suite.
